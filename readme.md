# AutoClicker — Автоматический кликер с анализом текста

Приложение для автоматического поиска и клика по элементам на экране на основе распознавания текста. Идеально подходит для повторяющихся операций в медицинских и других системах.

## 🎯 Основные возможности

- **Анализ текста на экране** — кликер ищет нужное слово/фразу
- **Плавающая кнопка с прицелом** — видишь точно где будет клик
- **Гибкая настройка** — задержка, поисковое слово, инверсия поиска
- **Полный лог операций** — все действия записываются с временем
- **Копирование лога** — сохрани результаты в буфер обмена

## 📋 Требования

- Android 8.0+ (API 26+)
- Доступ к службе специальных возможностей (Accessibility Service)
- Разрешение на отображение поверх других приложений

## 🚀 Установка и настройка

### 1. Включение Accessibility Service

1. Откройте приложение
2. Нажмите кнопку **"Включить Accessibility"**
3. Перейдите в *Параметры → Специальные возможности → Установленные сервисы*
4. Найдите **AutoClicker** и **включите его**

### 2. Разрешение на наложение

1. В приложении нажмите **"Показать кнопку"**
2. Если появится запрос разрешения — **разрешите** наложение поверх других окон

### 3. Настройка параметров

| Параметр | Описание | Пример |
|----------|---------|--------|
| **Поисковое слово** | Фраза, которую нужно найти на экране | "Бабай", "Найти пациента" |
| **Инверсия поиска** | Если включено, кликер ищет НЕ это слово | ✓ для поиска отсутствия |
| **Задержка (мс)** | Время между анализом экрана (500-50000) | 500, 1000, 2000 |

## 📱 Как использовать

### Основной цикл работы

```
1. АНАЛИЗ — читаем текст на экране
         ↓
2. ПОИСК — ищем нужное слово
         ↓
3. РЕШЕНИЕ:
   ✓ Найдено → ЗВУК + СТОП (миссия выполнена!)
   ✗ Не найдено → СВАЙП НАЗАД → КЛИК → обратно к АНАЛИЗУ
```

### Управление

1. **Включить/выключить** — нажми на плавающую кнопку с крестиком
    - 🟢 **▶️ Ищем...** — кликер работает
    - ⏸️ **Пауза** — остановлен

2. **Переместить кнопку** — перетащи её в нужное место (это прицел!)

3. **Посмотреть координаты** — двойной тап на логе (или очистить)

4. **Скопировать лог** — обычный клик на окне с логом

## 📊 Окна приложения

### Плавающая кнопка + Статус
```
[⊕] [🔍 Ищем...]
```
- **⊕** — кнопка управления (переместить за неё)
- **Статус** — текущее состояние (Пауза/Ищем)

### Лог событий
```
23:47:17 📄 Запуск цикла...
23:47:17 📍 Целевые координаты: x=128, y=160
23:47:17 🖱️ Клик x=128, y=160
23:47:17 📖 Вернуться назад...
23:47:17 🔍 'найти' НЕ=false Найдено=true
23:47:17 🎯 СОВПАДЕНИЕ! Остановка
```

## 🎮 Жесты

| Жест | Действие |
|------|----------|
| Клик на лог | Копировать содержимое в буфер |
| Двойной тап на лог | Очистить лог + показать координаты |
| Перетащить кнопку | Переместить прицел |
| Клик на кнопку | Вкл/выкл кликер |

## 🔧 Интеграция координат

Кликер использует **SharedPreferences** для сохранения координат плавающей кнопки:

```
buttonX — X координата левого края кнопки
buttonY — Y координата верхнего края кнопки
clickX = buttonX + 28 — центр клика по оси X
clickY = buttonY + 60 — центр клика по оси Y
```

**Центр клика вычисляется динамически** на основе текущей позиции кнопки!

## 🐛 Типичные проблемы

### Кликер не работает
- ✓ Проверьте что Accessibility Service **включен**
- ✓ Разрешите **наложение поверх других окон**
- ✓ Попробуйте **Clean Project** → **Rebuild Project** в Android Studio

### Клик не туда попадает
- ✓ Посмотрите координаты в логе
- ✓ Переместите плавающую кнопку ровно над целью
- ✓ Двойным тапом на логе проверьте текущие координаты

### Кликер не находит текст
- ✓ Проверьте правильность написания поискового слова
- ✓ Включите **инверсию** если ищете отсутствие текста
- ✓ Смотрите в логе что именно читается с экрана

### Accessibility Service отключился
- ✓ Перезагрузите устройство
- ✓ Заново включите сервис в параметрах
- ✓ Переустановите приложение

## 📝 Примеры использования

### Пример 1: Поиск пациента в системе EMIAS

```
Поисковое слово: "Найти пациента"
Инверсия: ✗ выключена
Задержка: 500 мс

Результат: кликер будет кликать до тех пор, пока не найдёт 
фразу "Найти пациента" на экране
```

### Пример 2: Проверка что что-то исчезло

```
Поисковое слово: "Ошибка"
Инверсия: ✓ включена
Задержка: 1000 мс

Результат: кликер кликает, пока НЕ исчезнет сообщение об ошибке
```

## 🔐 Разрешения

Приложение требует:
- `SYSTEM_ALERT_WINDOW` — отображение поверх других приложений
- `FOREGROUND_SERVICE` — служба переднего плана (для Accessibility)
- `BIND_ACCESSIBILITY_SERVICE` — доступ к AccessibilityService

```
MainActivity ← настройки + управление разрешениями
    ↓

    ↓
ClickerService ← основной алгоритм поиска и клика

```
